# PremiumCMS Bistro theme

Restaurant for PremiumCMS: a menu with modifiers and kitchen stations, delivery (postcode zones, fees, minimums), pickup and dine-in with QR table cards, table reservations, and a staff app with PIN sign-in — POS (cash / card / open tabs), cash drawer with Z reports, kitchen display per station and automatic ticket/receipt printing (browser agent or PrintNode).

Served by PremiumCMS as is, or forked to GitHub Pages with one-click theme updates. The seed sets up the dishes, tables, printers, staff PINs (demo: 1234 manager, 2345 server, 3456 kitchen, 4567 driver), opening hours, delivery zones and the Site Kit business profile.

## Pages

`/menu`, `/order` (QR: `/order?table=T4`), `/reserve`, `/track`, `/staff` (POS · Orders · Kitchen · Drawer · Printer).

## Plugins

`premium-commerce` (orders, menu = products), `premium-bookings` (table reservations), `premium-restaurant` (delivery zones, QR dine-in, POS, kitchen display, printing), `premium-forms`, `premium-site-kit`.
