# PremiumCMS theme

The premium-cms.com product site as a theme: landing page, pricing (rendered live
from the Platform plugin's public `pricing` route), sign-up / sign-in by email
link, the customer dashboard (credits, sites, new-site provisioning) and a blog.

This is the theme the platform's own site runs — premium-cms.com is its demo.
It needs the `premium-platform` plugin (the seed's pages carry the
`data-platform-*` markers its frontend fills). The generic starter every theme
builds on lives in `frontend-template/` at the repo root.
