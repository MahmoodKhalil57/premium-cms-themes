# PremiumCMS themes

The frontend template and the themes built on it. Empty — starting fresh.

```
frontend-template/   the shared template core: layouts, core pages, libs, styles, default seed
themes/<id>/         one theme: seed/ (content-as-code), theme.json, public/, screenshots
demos.json           the demo project for each theme
```

Theme history before the reset is in this repo's git log.
